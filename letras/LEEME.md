# Letras

Cada archivo de esta carpeta es la letra de un tema del disco, en orden.

Para cargar una letra:
1. Abrí el archivo del tema (por ejemplo `01-universo.txt`).
2. Tocá el lápiz (Edit) arriba a la derecha.
3. Pegá la letra tal cual, con sus saltos de línea.
4. Tocá **Commit changes**.

En un par de minutos aparece en la web, en Escuchar, al tocar "letra".
Si un archivo está vacío, la web muestra un link para leer esa letra en Bandcamp.
